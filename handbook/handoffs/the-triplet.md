## 2. Unfinished, and what done looks like

Ordered by what each unblocks.

1. **The show document's schema in the corpus** (plan Q3). Done: a schema file,
   and its cases generated by `codecarto show export` rather than written by
   hand, run by a test on both sides.
2. **`qm cookbook --check` reads the documents** (plan §7). Done: it fails
   when any of these holds:
   - a subject has no document and no stated absence;
   - a document's claims digest no longer matches its subject's rows;
   - a private name appears under `docs/show/`.

   It also shows each source commit's age against a budget.
   codecartographer's `codecarto/services/show_export.py` computes the digest
   over a subject's own rows; the corpus's side must compute the same one.
3. **A refresh protocol.** Done: a `ci/protocol-registry.yaml` entry with a
   `cadence_days`, and, if wanted, the plan's `--show` orchestration in
   `qm cookbook` running the exporter from a sibling clone.
4. **The seed's last three workflows.** `signature-check.yml`, `tag-claims.yml`
   and `timeless-check.yml` check out every submodule, which fails in a
   project with a private one. Done:
   - each checks out the governance submodule alone, as `adr-lint.yml` does;
   - codecartographer copies them at its next pin bump. Its
     `tests/test_seed_copies.py` fails, naming each, when the seed changes.
5. **Measured edges from the host.** The estate views' measured dependencies
   are read from clones on the exporting disk, without a commit. Done: each is
   measured from the member's default branch, and names its file and commit.
6. **A machine-free reason from the routes.** `scrub` refuses three phrases
   for "this machine", so a new phrasing would pass. Done: the show routes
   give a structured reason (`no_clone`, `off_head`), and the exporter writes
   its own sentence from it.
7. **The static viewer on codecartographer's Pages** (plan C5), the READMEs
   (R1), and dossier's terminal view (D1, D2). Each is a phase of the plan as
   written.
