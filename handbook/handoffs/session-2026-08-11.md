## Two defects fixed in the seed, which reach every project

- **`submodule-check.yml` called a pushed commit unpushed.** It fetched the
  `.gitmodules` URL as written, and a runner has no SSH key, so
  `git@github.com:…` always failed. It now translates to HTTPS, tries both, and
  when both fail says it cannot tell "not pushed" from "private remote,
  unauthenticated runner".
- **`run_workflows_locally.py` ignored `working-directory`.** A step ran at the
  repository root and reported a confident failure about a file one directory
  down. Now resolves step → job → workflow defaults, and a missing directory
  fails loudly rather than silently running at the root.

## What the release layer added

`harness-status.json` now carries, per repository, what a `v` tag asserts
beside what the default branch carries past it — `unreleased`, `current`, or
`ahead by N`. First run found **two lightweight tags** (`alfred@v0.2.0`,
`datum@v0.0.1`), which §6 of the version-tags record says cannot name a
reviewer or a manual test, and **nine repositories never tagged**.

## The methodological change

§8 of `records/DRAFT-decision-record-discipline.md` is new: a claim about what
facts *mean* must name what else could produce them. It exists because the two
worst errors of this session had entirely true facts underneath — a claimed
independent convergence that was one author and backwards in time, then an
over-correction that deleted the real finding. The retrospective is
`perspectives/2026-08-11-inflation-deflation-and-what-discovery-looks-like.md`.

Unlike every other clause here it has no mechanical check and never will. It is
carried by records naming the alternatives they ruled out.
