## The finding that mattered most

`codecartographer` pinned its governance submodule at a commit **on no remote
and in no clone but one machine.** A fresh checkout could never have resolved
that project's own submodule, and the only copy of a project record lived in the
same unreachable place. It survived by luck: a working tree was deleted and the
git objects happened to outlive it.

Two things came out of that, both merged:

- **`uv run qm pins`** (`qm` #91, #92) — every submodule pin is a commit
  somebody else could get. It separates *unpushed* (the remote is readable and
  lacks the commit — a hard failure) from *unreadable* (nobody here can read
  that remote at all — unknown, reported, never silently green). It also names
  branches inside a submodule's clone that are on no remote, because the pin
  can be perfectly good while the clone holds the only copy of something.
- **Two recoveries** (`qm` #90, #93) — a project record and a perspective, each
  rescued from a single clone and landed.

`qm pins` found the second of those within minutes of existing, in a repository
nobody was looking at. **Run it on any machine you are about to tidy.**

## Standing constraints

These are not negotiable and a fresh session will not infer them:

1. **Nothing unattended may spend.** Every paid call is a direct, deterministic,
   human-issued command. `qmcp/spend.py` is what any module calling a paid
   service must pass through; `records/DRAFT-no-unattended-spending.md` is the
   decision. Zero is the default *and a real count*: a zero-budget command does
   every free thing, establishes what the paid work would cost, and stops.
2. **The thread archive must never be published.** It carries conversation
   titles, session identifiers and repository names. Nothing caches a
   transcript, and no test fixture contains real archive material.
3. **Human-only contributorship.** No `Co-Authored-By:` trailer, no model name
   in any commit or record.
4. **Never bypass signing or hooks**, and never pass `-c` to git at all.
5. **One open pull request per repository, per contributor.** Drafts count.
   `project/<name>` branches are exempt, each holding its own slot.
6. **A pull request states decisions, not questions**, and you merge your own
   once the gates are green.

## Decided, not built: qmcp as the model layer

The operator's decision, on 2026-08-23: **dossier should use qmcp as the
communication layer to and from all language models.** dossier never calls a
model; qmcp does. That matches the shape already in place — qmcp owns the data
and serves HTTP, the two front ends read it.

Nothing is built. What exists to build on:

- `qmcp/spend.py` — the budget gate above. **Every send must pass through it.**
- `qmcp/localmodel.py` — standing a local model up; checks, then proposes, then
  a person runs the commands.
- `qmcp/threads/` — three read-only sources (`claude`, `chatgpt`, `claude-code`)
  and **nothing writable**. A conversation started here needs a source that can
  be written, which does not exist.
- `dossier/chat.py` and `ChatScreen` — the reading half, merged and working.

## Frictions found and not fixed

- **`dossier`'s governed loop cannot run while `dossier dashboard` is running.**
  `uv sync` must replace `.venv/Scripts/dossier.exe` and the running process
  holds it (`os error 32`). Suites were run with `--no-sync` against the same
  environment. A project whose loop cannot run while the project runs is a
  friction nobody chose.
- **`uv run qm mutate` cannot measure `ci/trio_demo.py`** — it copies the module
  to a temp directory where the demo can no longer find its sibling
  repositories, so the baseline is red before an operator applies. Its mutations
  were done by hand; the limitation is written beside its tests so the absence
  is not read as a choice.
- **GitHub Actions was switched off** at the repository level for
  `codecartographer`. Enabling it immediately failed three workflows that had
  never run a line of their own logic. It is on now.

## What to distrust in this page

- **Every figure is from one run at one commit.** Re-derive.
- **"All green" means the gates that exist.** `qm review` is structural: nothing
  has read a record for meaning or compared two records for contradiction. That
  pass is a human reading all of them in one sitting, and it has not happened.
- **A local pass is evidence, not proof.** The suites ran CI's arguments, not
  CI's environment.
- **`qm pins` reports nothing in CI, and that is not a pass.** A runner clones
  each submodule fresh and holds no local branches. The question only has an
  answer on the machine where the work was done.
