## Faults nothing caught

An independent reviewer broke the first version of the gathering and then
broke its tests: of twenty-seven faults deliberately injected into the code,
twenty-four were caught by nothing. Every test written after it names the
fault it holds shut. The tests of a person's half had the same shape: three
tests skipped themselves when nothing was undecided, so the whole
question-ranking mechanism could be deleted with the suite still green; a
mutation making the command ignore `--answers` entirely survived the suite,
which is how `--ask` came to overwrite a person's notes unnoticed; the
flagship refusal came out as thirty lines of internal detail; and a reviewer
pointed out that the guard keeping the picture path off the network covered
half the path.

An independent review of the picture path set out to break it rather than
confirm it, and every hard case it wrote failed before it passed: treating
both of a picture's directions as its width stretched every ordinary
photograph by a third; an object filling the frame came back as one shape
covering the whole picture, more confidently than the right answer; a speckle
floor tied to the picture's size threw three dots away in a thumbnail and kept
them in a photograph; and a ruler photographed at a tilt, measured by its
upright box, scaled the build a third too big. All of it landed with the
gathering on 2026-08-28. A green suite says only what its tests hold, and a
mutation review measures that.

## The suite's own scaffolding

The browser tests' options were defined in their own `conftest.py`, and pytest
parses arguments before it loads a `conftest.py` below every path named, so
`pytest tests walkthrough` refused its own `--start-server` as "unrecognized
arguments" (2026-08-28). A screenshot written again on every run left every
tracked picture modified until a picture was written only when its pixels
changed (2026-09-26). The demo's last browser test ran last of all, after
every test with a browser, on a second demo of its own, and found none of the
first one's pictures (2026-10-12). A wall-clock bound on a jog measured the
machine's load rather than the page, so the test checks the order of events
(2026-09-28). A ring's answer was seen to take over five seconds on a machine
busy with OpenSCAD, which set how long a browser test waits for a ring
(2026-10-10). And because the viewer was once read, believed and found not to
work without a network, the gathering's map is driven in a browser with the
network off rather than inspected.
